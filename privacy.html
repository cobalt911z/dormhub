นโยบายนี้อธิบายว่าเว็บไซต์ KMUTNB Dorm Hub จัดการข้อมูลและสถิติการใช้งานอย่างไร เว็บไซต์นี้เป็นเว็บข้อมูลที่พักซึ่งจัดทำเพื่อชุมชนนักศึกษา ไม่ใช่เว็บไซต์ทางการของมหาวิทยาลัย และเป็นเว็บแบบ static ที่ไม่มีบัญชีผู้ใช้หรือระบบส่งข้อมูลประกาศไปยังเซิร์ฟเวอร์ของเว็บไซต์

ผู้ดูแลเว็บ: ต้องกรอกข้อมูลก่อนเปิดเว็บไซต์จริง

โปรเจกต์ยังไม่มีชื่อ/ที่อยู่ของผู้ควบคุมข้อมูล ช่องทางติดต่อโดยตรงสำหรับคำขอใช้สิทธิ์ และรายละเอียดผู้ให้บริการโฮสต์/ระยะเวลาเก็บ GA4 ที่ยืนยันได้ ข้อมูลเหล่านี้ต้องกรอกให้เป็นจริงในส่วน “ผู้ควบคุมข้อมูลและการใช้สิทธิ์” และตรวจการตั้งค่าผู้ให้บริการก่อนเผยแพร่ นโยบายนี้จึงยังไม่ใช่การรับรองว่าปฏิบัติตามกฎหมายครบถ้วน

ผู้ควบคุมข้อมูลและการใช้สิทธิ์

ผู้ควบคุมข้อมูลส่วนบุคคล: ผู้ดำเนินการ KMUTNB Dorm Hub — [กรอกชื่อบุคคลหรือนิติบุคคลตามจริง]

ที่อยู่สำหรับติดต่อ: [กรอกที่อยู่ติดต่อของผู้ควบคุมข้อมูล]

ช่องทางติดต่อเรื่องข้อมูลส่วนบุคคล: [กรอกอีเมลหรือช่องทางส่วนตัวที่ผู้ดูแลตรวจสอบได้]

หากมีการแต่งตั้งเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) หรือกฎหมายกำหนดให้ต้องมี ให้ระบุชื่อ/ช่องทางติดต่อ DPO: [กรอกเมื่อเกี่ยวข้อง] ช่องทางกลุ่ม Facebook เป็นช่องทางแจ้งปัญหาประกาศทั่วไป ไม่ควรใช้ส่งเอกสารหรือข้อมูลอ่อนไหวเพื่อยืนยันตัวบุคคล

เจ้าของข้อมูลอาจยื่นคำขอตามสิทธิที่กฎหมายกำหนด เช่น ขอเข้าถึงหรือสำเนา ขอแก้ไข ขอให้ลบ/ทำลายหรือระงับการใช้ คัดค้านการประมวลผล ขอรับ/โอนข้อมูลเมื่อเข้าเงื่อนไข และถอนความยินยอมที่เคยให้ไว้ ผู้ควบคุมข้อมูลจะตรวจสอบคำขอและดำเนินการตามหลักเกณฑ์และข้อยกเว้นของกฎหมาย รวมถึงแจ้งเหตุเมื่อไม่สามารถดำเนินการได้ตามที่กฎหมายกำหนด เจ้าของข้อมูลมีสิทธิร้องเรียนต่อ สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.) ↗ ได้ตามกฎหมาย

1. ข้อมูลที่จัดเก็บในอุปกรณ์ของคุณ

ระบบจัดการประกาศ (CMS) ใช้ localStorage และ sessionStorage ของเบราว์เซอร์ เพื่อเก็บรายการประกาศและฉบับร่างที่คุณเพิ่ม/แก้ไข รูปแบบธีม ลิงก์ติดต่อ ค่าความยินยอมต่อ Google Analytics และสถานะการแสดงป๊อปอัป ข้อมูลนี้อยู่ในอุปกรณ์และเบราว์เซอร์ปัจจุบัน ไม่ซิงก์ไปยังเครื่องอื่น

CMS ไม่มีระบบสมาชิกหรือการยืนยันตัวตน ผู้ที่เปิดหน้า CMS บนอุปกรณ์เดียวกันอาจเห็นหรือแก้ข้อมูลในเบราว์เซอร์นั้นได้ อย่าใช้เก็บข้อมูลอ่อนไหว ข้อมูลบัตรประชาชน รหัสผ่าน หรือข้อมูลที่ไม่ควรเปิดเผยต่อสาธารณะ และอย่าเปิดเผยไฟล์สำรอง JSON ที่อาจมีเบอร์โทร/ข้อมูลติดต่อของบุคคลอื่น

เมื่อผู้ดูแลนำข้อมูลจาก CMS ไป export หรือใส่ในไฟล์เว็บไซต์แล้ว deploy ข้อมูลนั้นอาจถูกดาวน์โหลดและทำสำเนาได้โดยผู้เข้าชมทั่วไป การลบจากหน้าเว็บภายหลังไม่สามารถรับประกันการลบสำเนาจาก cache หรือบุคคลที่ดาวน์โหลดไปแล้ว

คุณลบข้อมูล CMS ในอุปกรณ์นี้ได้โดยล้างข้อมูลเว็บไซต์/ข้อมูลการจัดเก็บของโดเมนผ่านการตั้งค่าเบราว์เซอร์ การลบอาจทำให้ฉบับร่างและการตั้งค่าหายไป

2. Google Analytics และความยินยอม

เมื่อผู้ดูแลตั้งค่า GA4 Measurement ID เว็บไซต์จะแจ้งวัตถุประสงค์และขอความยินยอมก่อนโหลดสคริปต์ หากปฏิเสธ คุณยังใช้การค้นหาที่พักได้ตามปกติ การใช้ Analytics อาศัยความยินยอมตามวัตถุประสงค์นี้ และไม่ควรนำความยินยอมไปผูกกับการใช้บริการหลัก

หลังยินยอม ระบบอาจส่ง page view, รหัสรายการประกาศ, การกดลิงก์/แผนที่/โฆษณา, การใช้ตัวกรอง และข้อมูลทางเทคนิคของอุปกรณ์/เบราว์เซอร์ที่ GA4 เก็บตามการตั้งค่า ระบบไม่ส่งข้อความค้นหาหรือเนื้อหาที่พิมพ์ในฟอร์มเป็น event ที่เว็บไซต์กำหนด อย่างไรก็ตาม URL หรือข้อมูลที่ผู้ใช้เปิดอาจมีข้อมูลส่วนบุคคลได้ โปรดอย่าใส่ข้อมูลส่วนบุคคลใน URL, ชื่อประกาศ หรือเนื้อหาที่จะเผยแพร่

ผู้ให้บริการ: Google LLC และ/หรือบริษัทในเครือ ตามผลิตภัณฑ์และเงื่อนไขที่ใช้ การประมวลผลหรือจัดเก็บอาจเกิดนอกประเทศไทย ต้องตรวจสอบเงื่อนไขการประมวลผลข้อมูล มาตรการคุ้มครองการโอนข้อมูลไปต่างประเทศ และการตั้งค่า Google Analytics ของผู้ดูแลก่อนใช้งานจริง

ระยะเวลาเก็บ GA4: [ผู้ดูแลต้องตรวจและระบุค่าระยะเวลา data retention ที่ตั้งไว้ใน GA4 property] การถอนความยินยอมจะหยุดการส่ง event ในครั้งต่อไป แต่ไม่ลบข้อมูลที่ Google ได้รับไปแล้ว การเปลี่ยน/ถอนทำได้จากปุ่ม “ตั้งค่าความยินยอม” ในหน้าแรก

ดูเพิ่มเติมได้ที่ นโยบายความเป็นส่วนตัวของ Google ↗

3. คุกกี้และการจัดเก็บในเบราว์เซอร์

เว็บไซต์ใช้ local/session storage ของเบราว์เซอร์เพื่อจดจำประกาศ การตั้งค่า และความยินยอมตามที่อธิบายข้างต้น ไม่ใช้คุกกี้เพื่อเข้าสู่ระบบหรือระบุตัวตนโดยเว็บไซต์เอง ทั้งนี้ Google Analytics หรือบริการภายนอกที่โหลดหลังการยินยอมอาจใช้คุกกี้หรือเทคโนโลยีที่คล้ายกันตามการตั้งค่าของบริการนั้น

หากคุณปิดกั้น storage ในเบราว์เซอร์ การจำความยินยอมและข้อมูล CMS อาจทำงานไม่ครบ และคุณอาจต้องเลือกความยินยอมใหม่เมื่อกลับมาใช้งาน

4. บริการและลิงก์จากบุคคลที่สาม

ในเวอร์ชันปัจจุบัน หน้าเว็บโหลดฟอนต์จาก Google Fonts และสคริปต์ Tailwind CSS จาก cdn.tailwindcss.com ตั้งแต่เปิดหน้าเว็บ การเชื่อมต่อบริการเหล่านี้เกิดก่อนการเลือก Analytics และอาจส่ง IP address/ข้อมูลเบราว์เซอร์ไปยังผู้ให้บริการของแต่ละบริการ ผู้ดูแลควรประเมินความจำเป็นและพิจารณาโฮสต์ทรัพยากรเองหรือแจ้งรายละเอียดผู้ให้บริการให้ครบก่อนใช้งานจริง ส่วน Google Analytics จะโหลดหลังยินยอมเท่านั้น

เมื่อคุณกดลิงก์ไปยัง Google Maps, Facebook หรือเว็บไซต์ประกาศที่พัก ผู้ให้บริการปลายทางจะได้รับข้อมูลการเชื่อมต่อของคุณตามนโยบายของผู้ให้บริการนั้น เว็บไซต์นี้ควบคุมการประมวลผลของปลายทางไม่ได้ โปรดอ่านนโยบายของเว็บไซต์ปลายทางก่อนให้ข้อมูลเพิ่มเติม

ผู้ให้บริการโฮสต์: [ระบุผู้ให้บริการจริง เช่น GitHub Pages เมื่อใช้บริการนั้น] ผู้ให้บริการอาจประมวลผลข้อมูลคำขอและบันทึกความปลอดภัยตามเงื่อนไขของตน ผู้ดูแลต้องตรวจนโยบาย ระยะเวลาเก็บบันทึก และการโอนข้อมูลข้ามประเทศของผู้ให้บริการที่ใช้งานจริง

5. วัตถุประสงค์ ฐานการประมวลผล และระยะเวลาเก็บ

ข้อมูลที่จำเป็นต่อการทำงานของ CMS และตัวเลือกการตั้งค่าถูกเก็บไว้ในเบราว์เซอร์เพื่อจดจำการใช้งานตามที่ร้องขอ ส่วน Analytics ทำงานเมื่อได้รับความยินยอม การแสดงข้อมูลประกาศสาธารณะอาจมีข้อมูลของผู้ลงประกาศหรือบุคคลอื่น ผู้ควบคุมต้องพิจารณาฐานกฎหมายและหน้าที่แจ้งเจ้าของข้อมูลที่เหมาะสมเป็นรายกรณีก่อนเผยแพร่ ห้ามถือว่าข้อมูลที่หาอ่านได้สาธารณะหมายความว่านำมาใช้ซ้ำได้เสมอ

ข้อมูลในเบราว์เซอร์คงอยู่จนกว่าผู้ใช้จะลบหรือแทนที่ ข้อมูลประกาศที่ deploy จะคงอยู่จนกว่าผู้ดูแลจะนำออกจากไฟล์และ deploy เวอร์ชันใหม่ ส่วนอายุข้อมูล Analytics และบันทึกของโฮสต์ต้องกำหนด/ตรวจจากการตั้งค่าและผู้ให้บริการจริงก่อนเผยแพร่

6. การรักษาความปลอดภัยและเหตุละเมิดข้อมูล

เว็บไซต์ไม่มีระบบบัญชีหรือฐานข้อมูล CMS ส่วนกลาง ผู้ดูแลควรจำกัดผู้ที่เข้าถึงอุปกรณ์และไฟล์สำรอง ตรวจสิทธิการเข้าถึง repository และหลีกเลี่ยงการเผยแพร่ข้อมูลเกินจำเป็น ผู้ให้บริการโฮสต์และบุคคลภายนอกอาจมีมาตรการและบันทึกการใช้งานของตนเองตามเงื่อนไขบริการ

หากสงสัยว่าข้อมูลส่วนบุคคลรั่วไหล ให้ผู้ควบคุมประเมินเหตุ จำกัดผลกระทบ เก็บหลักฐาน และแจ้งสำนักงาน/เจ้าของข้อมูลภายในกรอบเวลาและตามเงื่อนไขที่กฎหมายกำหนด โดยช่องทางติดต่อเพื่อรับแจ้งเหตุของผู้ควบคุมต้องระบุไว้ในหัวข้อด้านบน

7. ประกาศ รูปภาพ และสิทธิของบุคคลอื่น

ผู้ดูแลต้องตรวจสอบความถูกต้องและสิทธิในการใช้ข้อความ รูปภาพ แผนที่ เครื่องหมายการค้า และข้อมูลติดต่อก่อนนำขึ้นเว็บไซต์ การที่โพสต์หรือรูปเข้าถึงได้ในกลุ่มสาธารณะไม่ได้แปลว่าได้รับอนุญาตให้นำมาคัดลอกหรือเผยแพร่ซ้ำ และการระบุแหล่งที่มาไม่ได้ทดแทนการได้รับอนุญาตหรือฐานกฎหมายที่จำเป็น

ก่อนเผยแพร่ชื่อ เบอร์โทร LINE รูปบุคคล หรือข้อมูลที่ระบุตัวบุคคลได้ ผู้ดูแลต้องมีฐานกฎหมายที่เหมาะสม แจ้งเจ้าของข้อมูลตามหน้าที่ และจำกัดข้อมูลเท่าที่จำเป็น หากไม่มีสิทธิหรือยืนยันไม่ได้ ให้เก็บเป็นฉบับร่างโดยไม่เผยแพร่ ใช้ลิงก์ไปยังโพสต์ต้นทางแทนการคัดลอกรูป/ข้อมูลเมื่อเหมาะสม และนำออกโดยเร็วเมื่อพบข้อโต้แย้งที่มีเหตุ

เว็บไซต์เป็นแหล่งรวมข้อมูล ไม่ใช่ผู้ให้เช่า นายหน้า หรือผู้รับรองประกาศ ราคา ห้องว่าง และเงื่อนไขอาจเปลี่ยนแปลง ผู้ใช้ควรตรวจสอบกับผู้ประกาศโดยตรง เว็บไซต์ไม่ควรรับข้อมูลการชำระเงินหรือเอกสารยืนยันตัวตนผ่านช่องทางนี้ หากรายการแนะนำหรือป๊อปอัปเป็นโฆษณาหรือได้รับค่าตอบแทน ผู้ดูแลควรระบุสถานะโฆษณา/ผู้สนับสนุนให้ชัด และตรวจข้อความไม่ให้เป็นเท็จหรือทำให้เข้าใจผิด

ผู้ดูแลควรปฏิบัติตามกฎหมายลิขสิทธิ์ด้วย การให้เครดิตแหล่งที่มาอย่างเดียวไม่ทำให้การทำซ้ำภาพหรือข้อความได้รับอนุญาต

8. การติดต่อ ขอแก้ไข หรือลบข้อมูล

คำขอด้านข้อมูลส่วนบุคคลควรส่งผ่านช่องทางติดต่อโดยตรงของผู้ควบคุมที่ระบุไว้ในหัวข้อด้านบน ไม่ควรโพสต์เบอร์โทร เอกสาร หรือข้อมูลอ่อนไหวในกลุ่มสาธารณะ หากยังไม่ได้กรอกช่องทางติดต่อดังกล่าว ให้ผู้ดูแลตั้งค่าก่อนนำเว็บไซต์ขึ้นใช้งานจริง

การแจ้งแก้ไขประกาศทั่วไปทำได้ที่ กลุ่มหอพัก มจพ. บน Facebook ↗ โปรดส่งเฉพาะข้อมูลที่จำเป็น

หมายเหตุด้านกฎหมาย: นโยบายนี้เป็นคำอธิบายการทำงาน ไม่ใช่คำปรึกษาหรือการรับรองการปฏิบัติตามกฎหมายทุกกรณี ผู้ดูแลควรตรวจสอบกับผู้เชี่ยวชาญก่อนดำเนินการจริง โดยเฉพาะการเผยแพร่ข้อมูลติดต่อ/รูปจากบุคคลอื่น การโอนข้อมูลไปต่างประเทศ และการกำหนดระยะเวลาเก็บข้อมูล อ้างอิงพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ซึ่งสามารถค้นฉบับประกาศในราชกิจจานุเบกษาได้ที่ เว็บไซต์ราชกิจจานุเบกษา ↗ และแนวทางจาก สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล ↗
